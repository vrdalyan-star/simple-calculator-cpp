# Simple Calculator C++  

Kalkulator sederhana yang dibuat untuk latihan C++.  

## Fitur 
- Penjumlahan(+)
- Pengurangan (-)
- Perkalian (*)
- Pembagian (/)
- Modulus atau sisa bagi (%)

## Yang dipelajari 
- Variabel
- Input dan output (cin, cout)
- Percabangan (if, else if)
- Tipe data int

## Contoh Input  + 5 2  
## Output  5 + 2 = 7
